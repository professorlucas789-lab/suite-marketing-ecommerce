## 🆘 Se Tiver Problemas

### "Não consigo encontrar o menu Diagnóstico"
```
1. Certifique-se que está logado como ADMIN
2. O menu deve estar em Administrativo (junto a Backup)
3. Se não aparecer, tente:
   - Recarregar a página (F5)
   - Fazer logout e login novamente
   - Limpar cache do navegador
```

### "O script não funciona"
```
1. Verifique que executou no DevTools Console
2. Verifique que está logado
3. Se der erro, copie o erro e envie-me
```

```
1. Vá a DevTools Console (F12 → Console)
2. Procure mensagens de erro em vermelho
3. Copie a mensagem e envie-me
```
